# Hospital Cost Report Analysis

An end-to-end analysis of hospital cost and operational data using Microsoft Excel and Power BI.

## Project Overview

This project focuses on analyzing hospital cost and operational data to identify key patterns, trends, and performance insights.

The project includes data preparation and analysis in Excel, followed by an interactive Power BI dashboard for visual analysis and reporting.

## Tools & Technologies

- Microsoft Excel
- Power Query
- Power BI
- Power BI DAX
- Data Visualization

## Project Files

### Data
- Raw hospital cost report dataset
- Excel workbook containing the data analysis

### Power BI
- Interactive Power BI dashboard
- Dashboard report file

## Key Analysis Areas

- KPI tracking
- Interactive data visualization

## Key Skills Demonstrated

- Data cleaning and preparation

- KPI reporting
- Business-oriented data analysis

## Outcome

The project transforms raw hospital data into structured analysis and an interactive dashboard, making key information easier to explore and understand.
